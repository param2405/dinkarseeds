# Dinkar Seeds - Premium Homepage

A professional, modern homepage for Dinkar Seeds, an established Indian agricultural seed company.

## 📋 Features

- **Premium Design**: Corporate agricultural brand aesthetic
- **Fully Responsive**: Mobile, tablet, and desktop optimization
- **Smooth Animations**: Framer Motion for professional micro-interactions
- **Modern Tech Stack**: React 18, TypeScript, Tailwind CSS
- **Accessibility**: Semantic HTML and accessible components
- **Performance Optimized**: Fast load times and smooth scrolling

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Dependencies

- **React 18**: UI framework
- **TypeScript**: Type safety
- **Tailwind CSS**: Utility-first CSS
- **Framer Motion**: Animation library
- **Lucide React**: Icon library
- **Vite**: Build tool
- **react-intersection-observer**: Scroll detection for animations
